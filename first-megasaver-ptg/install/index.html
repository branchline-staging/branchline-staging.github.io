BRANCHLINE · APP INSTALLATION

Install PTG

Add Branchline Price Tag Generator to your device for quick access. Installation does not create a separate account; sign in using your assigned PTG credentials.

Install on this device

If no install button appears, use your browser’s menu and choose Install app or Add to Home Screen.

Ubuntu / Windows desktop

  1. Open the PTG website in Google Chrome or Microsoft Edge.
  2. Select the install icon in the address bar, or open the browser menu.
  3. Choose Install app and confirm.
  4. Launch Branchline PTG from your desktop or application launcher.

Android

  1. Open the PTG website in Google Chrome.
  2. Tap the browser menu, then choose Install app or Add to Home screen.
  3. Confirm and open PTG from your home screen.

iPhone / iPad

  1. Open the PTG website in Safari.
  2. Tap Share, then Add to Home Screen.
  3. Tap Add, then launch PTG from your home screen.

Important reminders

  • An internet connection is required to sign in and use secure PTG functions.
  • Installing PTG does not bypass account permissions or branch restrictions.
  • Updates are delivered through the website; you do not need to reinstall for every release.
  • For shared branch computers, sign out after use and do not save your password in the browser.
