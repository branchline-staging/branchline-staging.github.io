Branchline Workspace

Open Sales Tracker, Price Tag Generator, MegaFrame Studio and MegaFlyer Studio in one browser workspace. Each app keeps its existing Supabase backend.

Ubuntu and other computers

Open Branchline Workspace in your browser

Choose one of four modules. Sales Tracker and PTG retain their existing sign-ins; both Creative Studios require an authorized PTG Team Leader, Branch Admin or System Admin account. On Ubuntu, use Workspace in the browser without downloading software.

To add an app icon in Chrome, open Workspace and choose ⋮ → Cast, save, and share → Install page as app.

Open an app directly

Sales Tracker · Price Tag Generator · MegaFrame Studio (PTG protected) · MegaFlyer Studio (PTG protected)

Android and iPhone

Open Branchline Workspace on your phone →

  1. On Android, open the mobile workspace in Chrome and choose Install app or Add to Home screen.
  2. On iPhone, open it in Safari, then choose Share → Add to Home Screen.

Windows installers are not provided in isolated staging. Use the browser preview.
