Open Sales Tracker and Price Tag Generator in one window using the account details for each app.

Ubuntu and other computers

Open Branchline Workspace in your browser

Choose an app and sign in with your existing account. On Ubuntu, you can use Workspace in the browser with no download.

To add an app icon in Chrome, open Workspace and choose ⋮ → Cast, save, and share → Install page as app.

Open an app directly

Sales Tracker · Price Tag Generator

Android and iPhone

Open Branchline Workspace on your phone →

  1. On Android, open the mobile workspace in Chrome and choose Install app or Add to Home screen.
  2. On iPhone, open it in Safari, then choose Share → Add to Home Screen.

Windows installer

Download Branchline Workspace Setup.exe

  1. Run Branchline Workspace Setup.exe.
  2. Open Branchline Workspace from the Start menu.
  3. Choose Sales Tracker or Price Tag Generator and sign in with the details for that app.

This installer requires x64 Windows, an internet connection, and the Microsoft Edge WebView2 Runtime. Setup links to Microsoft’s download if the runtime is missing.
