# Cross-platform update notification pilot

Staging only. All web pages with a normal head/body (excluding auth/offline routes) are stamped with their assembled web revision. A same-origin manifest is checked at startup, when returning to the page, when online and every 15 minutes while visible. A manual check and a dismissible notification are provided. No forced refresh or download; save open work and reopen through the usual authenticated workspace. Protected Studio frames are not inspected or modified. No native Windows, Linux or mobile-store binaries are distributed. WebView launchers receive notifications only when loading the updated web page.

Run `node --test staging/tests/update-center.test.cjs`. Run the existing isolated staging assembly and hosted smoke tests before merging. Verify notification on desktop/mobile and old/new revisions, offline, dismissal, no cross-origin requests, authentication and unsaved Studio projects. The native launcher still needs a separately signed compatibility-aware bootstrap, release signing, Windows runtime tests and rollback validation. Do not publish candidate ZIPs as approved production updates. Account role bug is outside this web pilot.
