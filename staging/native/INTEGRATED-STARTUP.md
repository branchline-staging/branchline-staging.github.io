# Integrated Windows R6 launch candidate (staging only)

This is a continuation of merged PRs #4–7. Keep the original installed executable path, shortcut, WebView2 profile and four-module interface. No standalone Update Center installation, shortcut, service, scheduled task, registry change or elevation. The exact role-corrected R6 pilot is the only accepted production-builder input. Its actual device test is still required.

The local owner build verifies the exact pilot archive and embedded executable, embeds an owner-signed companion into the managed launcher, adds a private startup method, verifies all original managed resource bytes, and emits a new candidate for owner signing and real-device tests. The helper is extracted to a hash-named internal file in the original installation folder and verified before launch. Tampered, missing or unsupported internal files never block the workspace. The helper is hidden until it has a verified update; it checks on launch, network reconnection and its existing timer, and stops when the owner workspace is closed and no notification is visible. It reuses the signed release policy, transaction, backup, receipt and user-confirmation logic; it does not accept WebView commands or network-supplied executables outside the signed policy. The helper and launcher remain separate process components of one installation, not separate applications.

CI validates the patcher with a harmless fixture executable, not the actual R6 runtime. Exact production launcher and signed companion must be built on the owner workstation using the pinned signing identity. After the role pilot passes, use build-companion.ps1, sign its output, then build-integrated-launcher.ps1 with -ConfirmRolePilotTested. Sign the resulting Branchline Workspace.exe. The original signed bootstrap installer must preserve path/shortcut and profile; no package is ready for distribution until the real install and next-release test pass. Never distribute CI test builds or expose private keys. No native production endpoint is opened by this PR.
